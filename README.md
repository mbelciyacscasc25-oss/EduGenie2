# 🎓 EduGenie

## Google Gemini Powered Learning Assistant

EduGenie is an AI-powered learning assistant designed to help students learn, practice, and understand concepts using Artificial Intelligence.

## 🌐 Live Demo

👉 **[Launch EduGenie](https://edugenie2.onrender.com)**

## ✨ Features

- 🤖 **AI Learning Assistant** – Ask questions and get educational explanations.
- 📝 **AI Quiz Generator** – Generate multiple-choice quizzes based on any topic.
- 📄 **PDF Notes Summarizer** – Upload PDF notes and generate simplified summaries.
- 💻 **Code Explainer** – Understand programming code with AI-powered explanations.
- 🔐 **User Authentication** – Register and login securely.
- 📊 **Progress Tracking** – Save quiz scores and track learning progress.
- 🔄 **AI Fallback Support** – Provides fallback responses when the AI service is temporarily unavailable.
